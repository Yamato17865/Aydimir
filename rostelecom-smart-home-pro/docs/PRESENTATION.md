# Структура презентации (10 слайдов)

1. **Smart Home PRO** — единая точка управления домашней средой; автор и конкурс.
2. **Проблема** — разрозненные приложения, отсутствие общей картины, ручные повторяющиеся действия.
3. **Решение** — панель устройств, события, автоматизация и энергомониторинг.
4. **Пользовательский путь** — обзор → команда → автоматический сценарий → подтверждение в журнале.
5. **Архитектура** — Web UI, API, доменная модель, simulator adapter, rule engine, storage, SSE.
6. **Демонстрация №1** — движение → ночной свет.
7. **Демонстрация №2** — охрана → открытие двери → тревога.
8. **Надёжность и инженерия** — валидация, локальная работа, тесты, воспроизводимая симуляция.
9. **План развития** — MQTT-адаптер, RTSP/WebRTC, аккаунты и роли, production security, аналитика.
10. **Итог** — работающий программный прототип, понятная архитектура и следующий этап пилота.

## Рекомендация по выступлению

Не тратьте время на чтение всех слайдов. Покажите два сценария вживую, затем откройте тесты и архитектурную схему. Обязательно проговорите, что устройства виртуальные: ценность текущей версии — в работающей серверной логике и расширяемой архитектуре.
