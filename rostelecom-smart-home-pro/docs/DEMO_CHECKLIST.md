# Чек-лист перед выступлением

- [ ] Node.js 20+ установлен.
- [ ] `npm run check` проходит.
- [ ] `npm test` проходит.
- [ ] `npm start` запускает сервер на 4173 порту.
- [ ] Страница открывается на ноутбуке и в актуальном браузере.
- [ ] Разрешение экрана минимум 1280×720 (адаптивная вёрстка поддерживает мобильный экран).
- [ ] Сбросить `data/state.json`, если нужен чистый старт.
- [ ] Проверить сценарий движения → свет.
- [ ] Проверить охрана → открытие двери → тревога.
- [ ] Проверить изменение температуры и розетки.
- [ ] Открыть вторую вкладку и проверить SSE.
- [ ] Держать терминал с работающим сервером и резервную копию ZIP.
- [ ] Не заявлять наличие реального видеопотока, голосового движка или физического IoT.
